# 3.2 Modul Kurasi Harga & Otomasi Margin

## Alur Penawaran Harga
Supplier menginput **harga penawaran awal** (contoh: Rp10.000 atau Rp20.000). Sistem KGN/PINBAS kemudian memproses harga tersebut melalui **verifikasi algoritmik**.

## Perhitungan Margin & Fee Admin
Sebelum produk diterbitkan di marketplace, sistem secara otomatis:
- menambahkan **margin** (contoh: 25%), atau
- mengkalkulasi **potongan biaya administrasi**.

## Pemindaian HET (Harga Eceran Tertinggi)
Harga jual akhir disesuaikan dan dipastikan **tidak melampaui regulasi HET** komoditas yang berlaku.

---

## Ringkasan Alur

| Tahap | Proses | Contoh |
|-------|--------|--------|
| 1. Input | Supplier memasukkan harga penawaran awal | Rp10.000 / Rp20.000 |
| 2. Verifikasi | Pemeriksaan algoritmik oleh sistem KGN/PINBAS | - |
| 3. Kalkulasi | Penambahan margin / potongan fee admin | Margin 25% |
| 4. Pemindaian HET | Penyesuaian agar tidak melebihi HET | - |
| 5. Publikasi | Produk terbit di marketplace | - |
